# DHBlocker

A Chrome extension designed to block specific, unwanted web elements. 

Whether it is an intrusive newsletter pop-up, a floating video player, or a cluttered sidebar, DHBlocker lets you target and hide the elements that get in the way of browsing. I built this project to make reading and navigating the web a bit cleaner without needing a massive, heavy ad-blocker.

## Features
* Target and hide specific HTML elements on any webpage.
* Lightweight and fast, running entirely locally.

## Installation
Since this is not on the Chrome Web Store, you can load it locally:
1. Download or clone this repository to your computer.
2. Open Chrome and navigate to `chrome://extensions/`.
3. Toggle on **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the `DHBlocker` folder.
